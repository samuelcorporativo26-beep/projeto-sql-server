# projeto-sql-server
Projeto prático de Banco de Dados utilizando SQL Server, com criação de tabelas, relacionamentos e consultas SQL.
# 🗄️ Projeto SQL Server

## 📌 Sobre o projeto

Projeto prático desenvolvido durante meus estudos de Banco de Dados
com SQL Server.

O objetivo é praticar desde os fundamentos de SQL até consultas
mais elaboradas, trabalhando com criação e relacionamento de tabelas,
inserção de dados e consultas.

## 🛠️ Tecnologias utilizadas

- SQL Server
- SQL
- SSMS (SQL Server Management Studio)

## 📚 Conteúdos praticados

- Criação de bancos de dados
- Criação e alteração de tabelas
- PRIMARY KEY
- FOREIGN KEY
- IDENTITY
- NOT NULL
- UNIQUE
- DEFAULT
- CHECK
- INSERT
- UPDATE
- DELETE
- SELECT
- WHERE
- LIKE
- BETWEEN
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- Funções de agregação
- CASE

## 🚧 Projeto em desenvolvimento

Este projeto está sendo desenvolvido continuamente durante meus estudos,
com novos exercícios, consultas e funcionalidades sendo adicionados.

## 🎯 Objetivo

Consolidar meus conhecimentos em SQL Server através de projetos
práticos e desenvolver uma base sólida em Banco de Dados.
